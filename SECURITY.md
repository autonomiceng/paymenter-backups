# Security

There is no supported release series yet. Report against the revision you run.

Report vulnerabilities privately: on this repository, open **Security → Report a vulnerability**. Do not use public issues, discussions or pull requests for security problems.

Never post storage credentials, encryption keys, backup contents, database dumps, host paths from a real server or customer data publicly.

Include the affected revision, the impact and a minimal synthetic reproduction. Keep real server and customer evidence private.
